# Bronze ingestion runtime (ADR-0010). Pinned exactly: the ingest job runs unattended on a
# schedule, so a surprise minor bump must not be the reason a 06:00 run fails.
#
# `filesystem` is the S3/local destination extra (ADR-0003 — Bronze lands as raw JSONL in
# s3://<lake>/bronze/<source>/). It pulls in s3fs/fsspec.
# `sql_database` is the Postgres source extra (ADR-0002 system of record); it pulls SQLAlchemy,
# which handles reflection but brings no driver of its own.
dlt[filesystem,sql_database]==1.29.1

# The psycopg2 driver, as a wheel. `-binary` rather than source: it ships its own libpq, so a
# GitHub runner needs no `libpq-dev` apt step and the ingest job has no compiler on its
# critical path. The known caveat (its bundled libssl can clash inside another C extension's
# process) does not apply — this runs as a standalone script, not embedded in one.
psycopg2-binary==2.9.10
